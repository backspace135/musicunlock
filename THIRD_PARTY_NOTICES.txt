MusicUnlock / 音匣 — third-party notices

The native decoding implementations adapt algorithmic portions of Unlock Music:
https://github.com/rainlotus97/unlock-music
Source snapshot: 502a552 (master), version v1.10.0
Original project: https://github.com/unlock-music/unlock-music

Adapted files:
src/decrypt/{ncm,qmc,qmc_key,qmc_cipher,kwm,kgm,xm,tm,ncmcache}.ts
src/utils/tea.ts
public/static/kgm.mask (copied into the app by the build script)

These are original upstream paths, not directories included in this repository.
The implementations have been ported to native Swift (macOS) and to C++20
(the shared core in shared/core, used by Windows and Android). The upstream source tree
has been removed; only required KGM data (resources/kgm.mask) and test vectors
(tests/fixtures/qmc) are retained with attribution. The project's own code is
licensed under the root MIT LICENSE; the notices below continue to apply to
third-party-derived portions and data.

The original web UI, browser runtime, telemetry, and remote metadata services
are not included in the native app. SwiftUI interface and native batch workflow
are implemented separately. Decoding logic has been ported to Swift.

The native lyric workspace was independently implemented in Swift after reviewing
the workflow and public platform request patterns of MusicLyricApp v6.5:
https://github.com/maqianjun-1/MusicLyricApp
Repository snapshot: f5970561b2537915df8310dcf983dc2015b6eab1
That repository distributes a Windows executable without a source-code license.
No executable, decompiled source, native DLL, or other asset from MusicLyricApp
is redistributed with this app. Music platform requests go directly to their
first-party endpoints. Apple WebKit is used only for account authorization.

single header, shared/core/third_party/nlohmann/json.hpp, under the MIT License:

Copyright (c) 2013-2025 Niels Lohmann

Its license text is reproduced in shared/core/third_party/qrcodegen/LICENSE.MIT
