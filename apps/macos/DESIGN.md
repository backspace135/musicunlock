# 音匣 / MusicUnlock

## 方向

原生 macOS 音频与歌词文件工具。音频工作区围绕导入、转换和导出；歌词工作区围绕查找、编辑和导出。
沿用同一套原生队列、黑白灰配色与 Liquid Glass 控制层，不增加播放器或虚构音乐库。

## 参考与取舍

通过 Chrome DevTools MCP 查看官网和产品截图：

- [MediaHuman Audio Converter](https://www.mediahuman.com/audio-converter/)：借鉴紧凑、可扫描的文件队列，保留文件名、来源格式和逐项状态。
- [Permute](https://software.charliemonroe.net/permute/)：借鉴拖放与独立任务反馈；不照搬其照片卡片和高透明度背景。
- [XLD](https://tmkk.undo.jp/xld/index_e.html)：借鉴无损工作流，明确说明恢复原编码而非统一转码。

使用 frontend-design 和 ui-ux-pro-max。后者的自动建议偏向深色娱乐产品、绿色 CTA 与展示型页面，
与本工具不匹配，因此采用系统明暗适配、实用队列和黑白灰配色，避免套用生成建议。

## Tokens

只用黑、白、灰（R = G = B），不使用彩色强调色。深色对应 macOS 深色模式的窗口灰，不偏蓝；
层级靠字重、对比和玻璃；任务状态靠 SF Symbols 区分（勾 / 感叹号 / 虚线圆），不靠颜色。

| 语义 | 浅色 | 深色 |
| --- | --- | --- |
| 工作区 | #F2F2F2 | #1E1E1E |
| 主表面（减少透明度时） | #FAFAFA | #282828 |
| 主文字 / 操作 / 状态 | #1C1C1C | #F2F2F2 |
| 次文字 | #636363 | #A0A0A0 |
| 分隔线 | #E0E0E0 | #3A3A3A |

字体使用系统 San Francisco / 苹方，标题 23pt，行标题 13pt，辅助信息 12pt，数值使用等宽数字。
以 4/8pt 为间距单位；主区域边距 24pt；设置栏宽 268pt；窗口最小 880×600。
SF Symbols 提供一致的图标语言，原生控件保持焦点反馈与键盘行为。

## Apple Liquid Glass（用户指定）

面向 macOS 26+，使用 Apple 原生 API，不以自绘模糊冒充。
通过 Chrome DevTools MCP 阅读 [Applying Liquid Glass to custom views](https://developer.apple.com/documentation/swiftui/applying-liquid-glass-to-custom-views)。

- 添加文件、添加文件夹放在系统工具栏，由系统提供玻璃；主转换按钮使用 `.glassProminent`，次要按钮使用不着色的 `.glass`。
- 队列筛选使用原生分段控件，选中态由系统绘制。自绘玻璃胶囊会盖住选中文字，已弃用。
- 窗口底层是缓慢流动的灰阶 `MeshGradient`（`AmbientBackground`），延伸到标题栏下并隐藏工具栏背景。
  玻璃只有在背后有明暗变化时才会产生折射；纯色背景会让玻璃退化成灰板。只用明暗，不用色相：
  多色粉彩渐变、暖米色和蓝灰深色都试过，分别显得“AI 味”、透过玻璃偏红、偏绿或偏蓝。窗口失焦时暂停，约 30fps。
- 队列、检查器、歌词结果、编辑区、底栏和提示横幅都用 `liquidSurface`（`.glassEffect(.regular)`，圆角 20–22），
  去掉原来的实色卡片与描边，由玻璃自身的边缘高光分层。提示横幅使用极淡的灰色着色玻璃。
- 底栏与搜索按钮放在 `GlassCluster`（`GlassEffectContainer`）中并标注 `glassEffectID`：开始/停止、搜索/取消
  共用同一身份原地变形，“重试”“打开输出目录”“导出所选”出现时从主按钮分离，消失时融回。
- 输出路径按钮在检查器内使用普通表面，避免玻璃叠玻璃。
- 系统“减少透明度”使用不透明表面和纯色背景。

## 动效（用户指定）

- 工作区切换使用 `blurReplace`；空态、列表、筛选空态之间同样模糊交叉。
- 队列行、搜索结果和提示横幅以 `.settle` 进出：从上方轻微下落淡入，原地缩小淡出。
- 任务状态图标使用 SF Symbols 替换动画，完成时弹跳一次；转换中整行淡蓝底色；计数与进度文字使用滚动数字。
- 歌词选中高亮通过 `matchedGeometryEffect` 在行间滑动；切换歌曲或编辑标签时编辑区淡入。
- 拖入文件时整个窗口浮起一层着色玻璃，图标上下弹跳；空态唱片缓慢漂浮，拖入时抬起并倾斜。
- 行与歌单项悬停时出现浅色高亮。
- 所有隐式动画经 `.motion(_:value:)`，系统“减少动态效果”时立即生效、色场静止、不漂浮；离屏渲染同样关闭。

## 图标

`assets/AppIcon.svg` 是源文件：唱片从打开的匣子里升起，匣面带锁孔，表示“解开”。
在 Chrome 中渲染为透明的 `assets/AppIcon-1024.png`，打包脚本用 `sips` 生成 iconset；App 内空态直接显示同一个图标。
修改 SVG 后需要重新渲染 1024 母版。

## 交互

- 拖入、系统文件选择器、文件夹递归导入、Finder 打开文件、⌘O 都可加入队列。
- 转换在后台串行运行，避免同时把大量无损文件读入内存。状态显示文本与图标，不单靠颜色。
- 取消在当前文件处理后生效，未开始的文件保留；失败逐项展示，支持重试。
- 同名输出自动加序号，源文件不修改。导出位置和命名方式跨启动记忆。
- 过滤队列不影响批量任务；完成文件可在 Finder 显示，不能播放的格式不误报为转换失败。
- 音频转换不使用联网元数据；内嵌封面与音频标签在本地保留/恢复。歌词按用户操作直连平台，无遥测。
- 动效只用于反馈状态变化与层级（见“动效”），遵循减少动态效果、系统明暗模式、键盘导航与 VoiceOver。

## 歌词工作区（0.2）

设计审视：歌词是可编辑、带时间轴的文字文件，不采用网页式三栏仪表盘或专辑封面墙。
继续使用既有 Tokens 与系统字体，把空间留给歌词。左侧 300pt 可勾选结果列表，右侧为编辑区；
导出细项放原生设置 Sheet，避免与编辑区争夺宽度。唯一强调是当前选中歌曲的墨色细标与主导出按钮。

```text
┌ ● ● ●             [音乐解锁 | 歌词工具]      打开歌词  账号登录 ┐
│ 歌词工作台                                                     │
│ [来源] [类型] [歌曲、歌手或分享链接                     ] 搜索  │
│ 搜索结果 / 歌单                 │ 歌名 / 歌手 / 专辑           │
│ □ 歌曲  歌手  专辑              │ [原文|译文|罗马音|导出预览]  │
│ □ 歌曲                          │ 原生 TextEditor              │
│                                 │ 带时间戳歌词                 │
│                                 │                              │
│ [格式] 导出设置                 复制 / 目录  导出所选  导出当前 │
└───────────────────────────────────────────────────────────────┘
```

- 官方网页仅作为账号授权界面；歌词工具本身不使用 WebView，不依赖本地服务。
- 网易云二维码用 Core Image 生成，网络轮询随 Sheet 关闭取消；QQ 使用官方账号授权。
- 会话自动写入系统钥匙串，不提供手动 Cookie 输入框；状态明确为“会话已保存”，不假定永久有效。
- 网络错误、无歌词、缺少逐字数据、无时间轴的字幕输入均给出可执行的提示。
- 勾选批量与点击预览分开；后台串行导出，允许停止，保留已完成文件并列出逐首失败原因。
